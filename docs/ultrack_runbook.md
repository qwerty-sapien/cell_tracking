# Ultrack prototype — archived

The unsupported Ultrack prototype is not an active execution lane. Its source,
runner, tests, and historical runbook are retained under
`_ARCHIVE/unused_ultrack/` for provenance. No command in that archive is a
standing launch instruction.

Reactivation requires a new named mechanism, a supported isolated runtime, and
new tests; do not restore only the runner or the old orphan tests.
