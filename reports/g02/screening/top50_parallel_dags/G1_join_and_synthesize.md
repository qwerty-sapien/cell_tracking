# G1 — join and synthesize the six branches

> Load `DAG.md`, `SHARED_CONTRACT.md`, `../LIVE_STATE.md`,
> `runs/<run-id>/G0_dispatch_manifest.md`, and every terminal branch artifact.

## Objective / gate

Does the complete six-branch evidence set support a reproducible, dependency-safe
portfolio ranked by objective pertinence × feasibility × defensibility? **GO**
requires six terminal artifacts, disclosed negative results/configurations, valid
preregistrations, and a portfolio whose next actions respect every dependency.

## Tasks

1. Validate every branch artifact against the ten-field hypothesis card.
2. Mark each candidate as beta, alpha, governance enabler, research bet, plan, or
   guess; reject novelty claims that lack a named crowding defense.
3. Reconcile graph effects using the full frozen-scorer vectors and uncertainty/null
   envelopes; do not rank by proposal metrics or best-fold outcomes.
4. Penalize multiplicity and missing configurations. Do not silently drop a negative
   branch from the synthesis.
5. Rank the smallest complementary portfolio by the minimum family graph delta,
   division leverage, feasibility, and marginal mechanism diversity.
6. State which actions are locally executable, dependency-locked, or HUMAN-GATE.

## Output

Write `runs/<run-id>/G1_portfolio_synthesis.md`, include all six verdicts and a
proposed root `LEDGER.md` reconciliation row.

## Verdict

- **GO** — all six artifacts are auditable and at least one next action is grounded,
  locally falsifiable, dependency-safe, and not contradicted by a kill line.
- **PARK** — evidence is valid but no candidate earns further resources.
- **DEAD** — the portfolio's shared premise is compellingly falsified.
- **ESCALATE** — missing/invalid evidence or a required change to the frozen goal.

## Cascade

- On **GO** → proceed directly to `G2_owner_decision.md` in the same run.
- On PARK / DEAD / ESCALATE / HUMAN-DECISION → halt and report; do not advance.
