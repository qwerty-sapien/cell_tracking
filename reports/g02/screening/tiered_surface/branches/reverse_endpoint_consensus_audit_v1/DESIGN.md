# Reverse endpoint-consensus audit — frozen design

This audit is observation-distinct from the terminal authentic-reverse separator.
The terminal experiment learned over all actions using reverse/cycle descriptors.
This audit fits nothing and ranks nothing. It asks only whether a strong, literal,
time-reversal return to the same candidate endpoints can identify a tiny set of
exact occupied-endpoint swaps.

The candidate is accepted only if the authentic forward and separately inferred
reverse margins are both at least `0.50` against every baseline edge the N1 swap
would remove, and the returned reverse pair beats its returned no-link mass by at
least `0.25`. Candidates are then traversed in canonical identity/time/node order,
with at most two per video and 64 globally. Exact action endpoint ownership must be
disjoint. Evidence values never determine ordering.

Only after this set is sealed may its already-banked labels be read. The exact
44b6 APNCC graph opens only for 4–64 edits with at least four beneficial and zero
harmful actions. Otherwise the lane terminates as a justified no-op with delta
vector `0/0/0`. This is deliberately stricter than the full-population Bayes/AUC
surface: it tests the narrow high-precision exception, not another population-wide
selector.
