# DeepCenter redundancy test (R3 §7.1) — result note

Date 2026-08-08. Preregistered test from `dag_prompts/2026-08-07-score-ceiling-research/runs/R3_MULTI_MODEL_FUSION.md` §7.1, executed CPU-only.

## What was measured

Population: the 3,754 gap-candidate midpoints generated by R1's Candidate 3 LAP
gap-closer (`gap_close_multiframe_lap.py`) against the real cv57-FULL predicted
graph, of which 22 are GT-correct (`matched_any=True`). This substitutes for
the "already-known gap-recovery candidate midpoints" the report's design
called for but which do not exist on disk (the production pipeline's own
gap-recovery is disabled in every completed run, `deepcenter_*` and
`gap_pairs_selected` counters all read 0 in `run_stats.csv`).

**Caveat on the substitute population, stated up front:** these are raw
geometry-plausible candidates from an untuned LAP, not candidates that already
passed a motion-context gate the way the production `recover_strict_gap2`
mechanism's candidates would. They are likely noisier (a higher fraction of
clearly-wrong pairs) than the population DeepCenter would see in its real,
intended role. Results below should be read as "on this available substitute,"
not as a final verdict on DeepCenter's value in its actual production role.

## Results

| quantity | value | preregistered bar |
|---|---|---|
| Spearman ρ (DeepCenter vs. existing local evidence) | **0.194** (p=2.5e-33) | kill if ≥0.6; pass if <0.4 |
| AUC (DeepCenter alone vs. GT-correctness) | **0.6315** | kill if ≤0.55; pass if ≥0.65 |
| null control (shuffled DeepCenter labels): ρ | -0.006 | should be ≈0 — confirms test has power |
| null control: AUC | 0.483 | should be ≈0.50 — confirms test has power |

**Verdict: neither kill nor pass line clears — genuinely ambiguous, not a
manufactured middle result.** The redundancy check passes cleanly (ρ=0.194 is
well under the 0.6 kill bar, and under the 0.4 pass bar too — DeepCenter is
not simply restating the existing local evidence). The discriminability check
is the one that lands short: AUC 0.6315 clears the 0.55 kill floor by a
real margin (and the null control confirms the test itself has power — a real,
not spurious, signal exists), but falls 0.0185 short of the 0.65 pass bar.

**Honest read, not a rounding-up:** with only 22 positive examples, the AUC
estimate carries real sampling noise at this n — this is not "basically 0.65,"
it is a real signal too small to call by the preregistered bar as designed.

## What this does and doesn't license

- Does **not** license proceeding to build the 3-parameter logistic
  recalibration gate (§7.1's next step) — that step is explicitly staged
  "pass line clears first," and it hasn't.
- Does **not** support a KILL / do-not-pursue verdict either — the redundancy
  concern (the actual reason every public author's DeepCenter-as-veto attempt
  was reportedly net-neutral-to-negative) is not what's happening here;
  DeepCenter is measurably carrying information the existing local evidence
  lacks.
- The honest status is **parked, inconclusive on available data** — worth
  revisiting if either (a) the actual production gap-recovery candidate
  population becomes available (a cleaner, less noisy substitute), or (b) a
  larger n of GT-correct examples becomes available to shrink the AUC
  confidence interval.
