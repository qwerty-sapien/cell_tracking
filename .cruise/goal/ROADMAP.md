# G-02 Roadmap

## Phase 0 — Pre-Start plan review

Archive G-01 byte-for-byte, retain the runtime origin, and review this candidate. No model change, test, network access, or Kaggle action occurs in this phase.

## Phase 1 — Trustworthy evaluation foundations

T-02 locks the official scorer fixture/candidate-pair protocol and group/audit split registry before fitting. It makes the measured historical alpha result a baseline only.

## Phase 2 — Compact learned hybrid

T-03 adds the released-checkpoint shared backbone and output heads. T-04 builds KD-tree candidate gating, lightweight learned edge scoring, and global constrained lineage solving. T-05 establishes the three specialists and OOF router.

## Phase 3 — Promotion and performance

T-06 uses cached 10/30/100 percent successive halving, applies the division activation rule, and promotes only candidates meeting metric/graph/runtime gates. T-07 packages the promoted candidate and measures end-to-end timing.

## Phase 4 — External calibration and endpoint

T-08 performs only predeclared, ledgered private Kaggle experiments inside cost/concurrency/submission caps. T-09 calibrates local to returned site scores without changing frozen roles. T-10 reruns full local/audit/runtime/package checks and creates or verifies the qualifying private Kaggle submission.

## Phase 5 — Independent closure check

T-01 reads all artifacts adversarially. It can PASS only when local, audit, package, runtime, graph, cost, and displayed Kaggle site evidence all satisfy the locked endpoint. It does not modify any file or external system.

## Milestones and hard gates

| Milestone | Entry gate | Exit gate |
| --- | --- | --- |
| M-01 foundation | Start approved | Immutable grouped split/audit and scorer fixture manifests pass E-01/E-02. |

| M-03 promoted router | M-02 | Specialist/router regret gates, HPO promotion gates, and grouped CV >= `0.92`. |
| M-04 production readiness | M-03 | Untouched audit >= `0.92`, four-clip/runtime proxy gates, package and manifest pass. |

## Stop boundaries

Do not start a paid or scored external action without a recorded maximum charge/submission count and required local gates. Do not use the audit to select a candidate. Do not add divisions early. Stop rather than broaden any permission or lessen the metric, scorer, graph, runtime, or cost threshold.
