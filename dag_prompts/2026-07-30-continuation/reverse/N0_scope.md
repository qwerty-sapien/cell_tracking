# Reverse N0 — independent-source identity gate

> Load `skills/seeking-alpha/SKILL.md`, `DAG.md`, reverse terminal reports, campaign plan, and LIVE_STATE.

## Objective / gate

Can a new future-evidence mechanism use an independently sourced observable and differ
materially from authentic Reverse Trackastra's endpoint-return association evidence?

## Tasks

1. Record the exact supplier/model/asset/contract exclusions from terminal evidence.
2. Generate 3 candidates using causal inference, self-supervised temporal consistency,
   or another independent novelty generator.
3. For each candidate state source provenance, changed information, failure mode,
   objective-linked observable, and a reason it is not a renamed reverse supplier.

## Output

Write `runs/N0_SCOPE.md` with a proposed (not written) LEDGER row.

## Verdict

- **GO**: one candidate has independent evidence, a distinct observable, and a test sketch.
- **PARK**: distinct candidates lack a reliable observable or source.
- **DEAD**: candidates repeat the terminal Reverse Trackastra mechanism.
- **ESCALATE**: an exception to supplier/no-retry policy would be necessary.

## Cascade

- On **GO** → proceed directly to `N1_literature.md` in the same run.
- On PARK / DEAD / ESCALATE / HUMAN-DECISION → halt and report; do not advance.
