# `TAP-SYM-DIV` Kaggle-first protocol draft — NOT AUTHORIZED

This conditional draft makes the N2 feasibility failure auditable. It is **not** a launch request, asset request, amendment, or authorization. N2 is `ESCALATE`, so it is intentionally non-executable.

## Required amendment before any work

The owner would have to amend the locked division plan to authorize this named representation experiment. The amendment must preserve the frozen scorer, 44b6-first graph gate, no current-pool refit, no oracle-continuity input, and no CV57, submission, RunPod, or tier action. It must separately approve source revision/weight/license, XY-from-volume transform, dependency wheels, and compute allocation.

## Data rights and exact subset

Only competition-provided **training raw intensity** Zarrs covered by the frozen five outer-fold manifests may be mounted in a private Kaggle kernel. For each outer fold, the encoder may read only that fold's fit-side raw frames; it may not read held-side raw frames, GT labels, official scorer material, continuity-target JSON, action population, submission/test images, or public/probe data. Raw frames and derived embeddings remain private. The owner must confirm competition use and retention terms before any dataset version is created.

## Preflight before model import or GPU work

1. Authenticate a pinned `tarrow` source revision and BSD-3-Clause license, with exact offline wheel hashes.
2. Authenticate raw-Zarr, outer-fold, and held/fit-disjointness manifests; prove count/SHA equality and empty intersections before extraction or import.
3. Validate the physical XY crop and `t-1,t,t+1` schema only on the analytic split/non-split fixture from `N2_FALSIFIER.md`.
4. Prove source-pinned GPU memory use fits the assigned Kaggle device. The upstream default expects >=24 GB; any lower-memory change is a new amendment, not a retry.
5. Emit a pure-stdlib receipt before packages, images, weights, or campaign-derived tensors are read.

## Hypothetical bounded execution and stop rules

The released source reports about 8 GPU-hours/model. Leakage control demands five fit-only encoders, hence 40 GPU-hours before inference. If ever approved, exactly one authenticated attempt per fold and **no retry** would be permitted. Stop before any outcome for a bad source/hash/license, wrong mount, held-frame intersection, failed synthetic contract, memory breach, runtime projection beyond fold budget, or any forbidden-field access.

Expected future artifacts would be a fit-manifest and encoder/hash receipt per fold, synthetic-contract results, held-side representation-evidence manifests, and a terminal no-action receipt. This stage could create no graph/action result.

The protocol is therefore **NOT ELIGIBLE FOR OWNER DECISION YET**. No Kaggle action, human amendment, or N3 request follows from this draft.
