but is **not** the terminal R5 768-D XY full-population projection or its transport?

1. Define the candidate's changed information, expected failure mode it addresses,
   exact distinction from R5 XY, and a fixture-level observable.
2. Use two novelty generators to list 3 candidates; reject any that reuse R5's input,
   full projection, package, or an existing supplier contract.
3. Select one candidate only if its causal path reaches delete/swap discrimination.

## Output

## Verdict

- **GO**: one candidate is materially distinct, observable, and nonterminal.
- **PARK**: candidates are distinct but no objective-linked observable exists.
- **DEAD**: every candidate is a renamed R5 retry.
- **ESCALATE**: an exception to R5's no-retry rule would be needed.

## Cascade

- On PARK / DEAD / ESCALATE / HUMAN-DECISION → halt and report; do not advance.
