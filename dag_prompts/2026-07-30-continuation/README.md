# 2026-07-30 continuation DAGs

Five independently dispatchable continuation lanes for the retained directions.  They
are intentionally research-first: each searches for a **new named mechanism**, grounds
it in primary literature, and writes a cheap falsifier before it requests compute.

The dispatcher starts at `N0` for every lane and auto-cascades only across `GO`.
`N3` in every lane is a HUMAN-GATE: it may prepare a Kaggle-first protocol, but it
must not create assets, launch a kernel, consume budget, submit, push, or use RunPod.
The live campaign state and its no-retry rules override every prompt.
